3 Nov 2026Update#

Added to the roadmap

  • Stage 1: Where You Inject Matters: The Trust Region Effect in LLM Agents (Guo et al.), the same injected instruction lands 2.6 times more often in a README or TODO file than in code or data.
  • Stage 3: Design Tenets for Agent Identity Management Systems (Booth, Fisher, Galluzzo, Clancy; NIST and MITRE), ten tenets for agent identity and authorization, including separation of policy from reasoning.
  • Stage 5: Blocking at the Boundary (Liu, Han, Lyu, Wang, Yu), a preprint on auditing each pending action against staged prompt injection in Claude Code and Codex.
  • Stage 7: INFUSE (Nguyen, Guo, Dubauskas, Damuluru, Johnson, Leach), an indirect prompt injection benchmark across 19 LLMs with code.
  • Stage 8: The Secure Software Factory: A Reference Architecture (Agent Baseline), four boundaries enforced outside the agent at three levels of autonomy; draft, open for comment.

Incidents table

  • Malicious Claude Code extension in Cursor's marketplace (Cursor), modified extension versions that planted an SSH key and persistence on Oct 29.
  • Unauthorized AI relays switch the sandbox off (Symantec), a relay that reconfigures genuine Codex and Claude Code CLIs to "danger-full-access" and routes traffic through its own servers.
  • MCPhantom (Glow Labs), coding agents installing archived MCP reference servers from training-data memory.

Link checks

  • All links added this week were opened and read before listing. The live README on GitHub may still be missing the Oct 22 and Oct 29 additions; upload the attached README.md and the weekly logs.
29 Oct 2026Update#

Added to the roadmap

  • Stage 3: Authority Is Not a String (Bouras, Dai, Mechtaev), CapScope: typed capabilities held outside the model, checked on every tool call.
  • Stage 6: LLM Agents Can Easily Tamper With Their Own Traces (Qin, Schmotz, Prinzhorn, Beurer-Kellner, Prabhu, Andriushchenko), why trace logging must sit outside the agent's control.
  • Stage 7: buried-injections (Rudratosh Shastri), a reproducible benchmark of 10 injection detectors on 629 AgentDojo attacks.

Incidents table

  • Mistral Vibe shell permission bypass (SecMate), a permission check that parsed one thing while the shell ran another; advisory.
  • Accessing and changing internal systems during dashboard research (OpenAI), a model that reverted a setting but kept the token it had obtained.

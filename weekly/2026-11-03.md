# Weekly update, 2026-11-03

## Added to the roadmap
- Stage 1: [Where You Inject Matters: The Trust Region Effect in LLM Agents](https://arxiv.org/abs/2610.38867) (Guo et al.), the same injected instruction lands 2.6 times more often in a README or TODO file than in code or data.
- Stage 3: [Design Tenets for Agent Identity Management Systems](https://www.nist.gov/blogs/cybersecurity-insights/design-tenets-agent-identity-management-systems) (Booth, Fisher, Galluzzo, Clancy; NIST and MITRE), ten tenets for agent identity and authorization, including separation of policy from reasoning.
- Stage 5: [Blocking at the Boundary](https://arxiv.org/abs/2610.05163) (Liu, Han, Lyu, Wang, Yu), a preprint on auditing each pending action against staged prompt injection in Claude Code and Codex.
- Stage 7: [INFUSE](https://arxiv.org/abs/2610.20776) (Nguyen, Guo, Dubauskas, Damuluru, Johnson, Leach), an indirect prompt injection benchmark across 19 LLMs with [code](https://github.com/judydnguyen/infuse).
- Stage 8: [The Secure Software Factory: A Reference Architecture](https://agentbaseline.org/reference-architecture) (Agent Baseline), four boundaries enforced outside the agent at three levels of autonomy; draft, open for comment.

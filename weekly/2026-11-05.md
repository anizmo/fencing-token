# Weekly update, 2026-11-05

## Added to the roadmap
- Stage 0: [The Protection of Information in Computer Systems](https://web.mit.edu/Saltzer/www/publications/protection/) (Saltzer and Schroeder, 1975), the design principles behind complete mediation and least privilege.
- Stage 2: [Strands Box](https://github.com/strands-agents/box) (Strands Agents, AWS), a preview sandbox that sends shell, Python, MCP, and network actions through one default-deny policy engine outside the agent.
- Stage 3: [Workflow Identity Hijacking](https://noma.security/noma-labs/workflow-identity-hijacking-the-silent-backdoor-in-ai-workflows) (Sasi Levi, Noma Labs), AI workflows that act with their creator's privileges on requests from anyone.
- Stage 7: [ToFu](https://arxiv.org/abs/2610.13651) (Ananto et al.), a fuzzer that found verified bugs in 343 MCP tools across 118 of 273 servers.

## Incidents table
- [ChatGPT Lockdown Mode bypass](https://research.checkpoint.com/2026/chatgpt-lockdown-mode-bypass-phishing-malware-delivery-and-silent-data-exfiltration/) (Check Point Research), a nested iframe reached an unwrapped `window.open`, and popups escaped the preview sandbox and Lockdown Mode; fixed by Sept 18.
- [Plugin4Shell](https://www.air.security/blog-posts/plugin4shell) (Air Security), coding agents installed attacker code past plugin SHA pinning because they never checked the commit they landed on.
- [GitSpawn](https://www.manifold.security/blog/ai-coding-agents-git-hijack) (Manifold Security), background git calls ran a repository's own `core.fsmonitor` command outside the sandbox.

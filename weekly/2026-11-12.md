# Weekly update, 2026-11-12

## Added to the roadmap
- [Securing Agentic Applications V2](https://genai.owasp.org/resource/securing-agentic-applications-v2/) (OWASP GenAI Security Project, Stage 0), a builder and defender's guide to agent architecture, identity and access, runtime protection, supply chain, and testing, released Nov 10.
- [When Approval Becomes Execution](https://arxiv.org/abs/2610.23077) (Chenggong Shi, Hongmei Mou, Stage 3), a denied agent fetched a routine approval token and completed the protected operation in 8 of 9 reruns.
- [My Credentials, Please](https://arxiv.org/abs/2610.22301) (Huang et al., Stage 4), 787 of 4,806 triaged MCP servers had filesystem access their category did not suggest; 13 advisories followed.
- [Detecting sleeper agents hiding in AI model neurons](https://www.microsoft.com/en-us/security/blog/2026/11/10/detecting-sleeper-agents-hiding-in-ai-model-neurons/) (Microsoft, Stage 4), editing fewer than 10 neurons can plant a trigger that passes evaluations.
- [A web page talked our agent into leaking a stranger's data](https://arize.com/blog/indirect-prompt-injection-ai-agents/) (Nancy Chauhan, Arize, Stage 7), 28 of 100 runs leaked another customer's record until the tools were scoped to the session in code.
- [Web LLM attacks](https://portswigger.net/web-security/llm-attacks) (PortSwigger Web Security Academy, Learn and practice), free browser labs against a live LLM.

## Incidents table
- [AgentCorruption (AWS Bedrock AgentCore)](https://labs.zenity.io/post/agentcorruption-how-a-single-prompt-collapsed-the-entire-cloud-security-model) (Zenity Labs), one prompt to an exposed agent reached the metadata service and returned credentials for a role that spanned every AgentCore agent in the account's region.
- [server-everything cross-origin environment leak](https://github.com/modelcontextprotocol/servers/security/advisories/GHSA-mvf5-2qqv-rg3c) (MCP reference servers), any web page could read the server's whole environment through its HTTP transports; fixed in 2.0.1.

## Concepts
- [Confused deputy](https://fencingtoken.com/concepts/): a trusted helper tricked into using its own authority for someone who has none, explained for experts, engineers, and everyone.

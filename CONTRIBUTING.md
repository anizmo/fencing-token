# Contributing to Fencing Token

Thanks for helping make AI agents safer. This list stays useful because it stays selective.

## What belongs here

- Tools, papers, specs, write-ups, incidents, and courses about **securing, containing, or auditing AI agents**.
- Things you would recommend to a senior engineer shipping an agent to production next month.

## What does not

- Generic "intro to LLMs" content.
- Vendor marketing pages with no technical substance.
- Abandoned projects, unless they are historically important (mark them as such).

## How to add an entry

1. Pick the right stage in `README.md`.
2. Use this format:
   ```
   - [Name](https://link). One sentence on why it matters to someone securing agents.
   ```
3. Note if the project is archived, research-only, or commercial.
4. Open a PR titled `Add: <name> (Stage N)`.

## Suggesting an incident

Open an issue with the **Incident** template: a link to a primary write-up, one line on what happened, one line on the lesson, and which stage it maps to.

## Recognition

Every merged contributor is credited in the weekly update and in the monthly Fencing Token newsletter spotlight.

## Code of conduct

Be kind, be specific, and assume good intent. Disclose affiliations when you add your own project.
